# 🎬 MovieFlix – Movie Management & Streaming Platform

## 📖 Project Overview

MovieFlix is a Netflix-inspired Movie Management System built using **Node.js**, **Express.js**, **MongoDB**, **EJS**, **Bootstrap**, and **Custom CSS**. The platform allows users to browse movies, view detailed information, watch trailers, save favorites, search movies, and explore movies by category.

---
